# GitHub Pages Summary

This folder contains the static repository page for the Unity GOAP triage-transport experiments.

To publish it on GitHub:

1. Open the repository settings.
2. Go to **Pages**.
3. Select **Deploy from a branch**.
4. Choose the target branch and set the folder to `/docs`.

The page is available locally at `docs/index.html`.

The page intentionally describes the workload as a **MIMIC-IV-ED demo-informed synthetic trace**. It should not be presented as a full MIMIC clinical validation dataset.

The standalone supplementary workload package is in `docs/dataset/`.
